# 中文节点选择器（Godot 4）

一个将 Godot 编辑器「添加节点」对话框**完全中文化**的编辑器插件。

按下 `Ctrl+A`（或点击场景树「+」按钮、右键「添加子节点」）时，会打开一个**复刻自原版**但全中文的节点选择对话框——节点名称、分类、描述全部是中文，还支持中英文双语搜索。

> 适用于 **Godot 4.7+**（基于 4.7.1 开发验证）。

---

## ✨ 功能

### 节点选择对话框（复刻原版 CreateDialog）
- **全中文界面**：节点名、分类、按钮、提示全部中文化
- **继承链分组**：按 Node2D / Node3D / Control / 其他 自动分组，抽象分类节点灰显
- **中英文双语搜索**：搜「精灵」或「Sprite」都能找到 Sprite2D
- **收藏 + 最近使用**：星标收藏常用节点，记录最近用过的节点
- **官方中文描述**：简要描述（加粗）+ 完整描述，来自 Godot 官方文档翻译；描述里的节点名引用自动翻译并高亮
- **实验性 / 弃用标记**：⚠️ 标记 experimental / deprecated 节点
- **类型过滤**：显示内置 / 自定义 / 编辑器

### 设置（⚙ 齿轮按钮）
- **自定义翻译映射**：未翻译的节点红色置顶，可直接编辑中文名，实时生效
- **数据保存范围**：收藏 / 最近使用 / 自定义翻译等可存「全局（所有项目共用）」或「仅当前项目」
- **入口劫持开关**：+按钮 / Ctrl+A 快捷键 / 右键菜单三个入口可独立开关（至少保留一个）

### 入口劫持
插件拦截 Godot 原版的「添加节点」入口，替换为中文对话框：
- **「+」按钮**
- **Ctrl+A 快捷键**
- **右键菜单 → 添加子节点**

均可在设置中独立关闭，关闭后该入口恢复原版（英文）对话框。

---

## 📦 安装

1. 将 `addons/中文节点选择器/` 文件夹复制到你的 Godot 项目 `addons/` 目录下
2. 打开项目 → **项目设置 → 插件** → 启用「中文节点选择器」
3. 重启编辑器（或直接使用）

## 🎮 使用

- 按 `Ctrl+A` 或点击场景树「+」按钮，即可打开中文节点选择对话框
- 右键节点 → 「添加子节点」同样生效
- 对话框右上角「⚙」进入设置：自定义翻译、保存范围、入口劫持开关

---

## 🔍 覆盖情况

- 动态扫描所有 Node 派生节点类型（约 250+）
- 内置 240+ 常用节点的中文名翻译 + 官方中文描述
- 未覆盖的新节点自动回退显示英文原名，可在设置中手动补全
