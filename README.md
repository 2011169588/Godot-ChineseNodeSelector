# 中文节点选择器（Godot 4）

一个将 Godot 编辑器「添加节点」对话框**完全中文化**的编辑器插件。

按下 `Ctrl+A`（或点击「+」按钮、右键「添加子节点」），会打开一个复刻自原版但全中文的节点选择对话框——节点名称、分类、描述全部中文，支持中英文双语搜索。

## ✨ 功能

- 全中文节点选择对话框（复刻原版 CreateDialog）
- 中英文双语搜索（搜「精灵」或「Sprite」都能找到）
- 收藏 + 最近使用
- 官方中文描述（简要 + 完整）
- 自定义翻译映射，未翻译节点置顶可编辑
- 入口劫持开关：+按钮 / Ctrl+A / 右键菜单

## 📦 安装

1. 将 `addons/中文节点选择器/` 文件夹复制到你的 Godot 项目 `addons/` 目录
2. 打开项目 → **项目设置 → 插件** → 启用「中文节点选择器」
3. 重启编辑器（或直接使用）

详细说明见 [插件目录内的 README](addons/中文节点选择器/README.md)。
