# 中文节点选择器（Godot 4）

将 Godot 编辑器「添加节点」对话框完全中文化的编辑器插件。插件会把节点名称、分类、描述全部显示为中文，并支持中英文双语搜索。

适用于 Godot 4.7+。

## 功能

- 全中文节点选择对话框
- 中英文双语搜索
- 收藏与最近使用
- 官方中文描述
- 自定义翻译映射
- 入口劫持开关

## 安装

1. 将 `addons/中文节点选择器` 文件夹复制到项目的 `addons` 目录
2. 在「项目设置 → 插件」中启用「中文节点选择器」

## 使用

按 Ctrl+A 或点击场景树「+」按钮，即可打开中文节点选择对话框。对话框右上角「⚙」可进入设置。
